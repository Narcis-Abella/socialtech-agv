# Point 7 kickoff: FAST-LIO2 submap → KISS-Matcher → small_gicp

Date: 2026-10-09. This is an implementation preflight, not an experiment or a compatibility claim.

- **Read in repository:** `01-investigacion-metodos.md` already surveyed and ranked the candidates, including the Humble Mid-360 FAST-LIO2/KISS/small_gicp wrapper by Ikunio. `02-protocolo-evaluacion.md` already defines the common 3D verification, alternative margin, multi-batch confirmation and truth firewall. No new survey or thresholds are introduced here. This checkout contains FAST-LIO2 build patches and the existing ROS nav bench, but no KISS-Matcher, small_gicp, or odometry-joined 3D submap builder. The reviewed upstream wrapper concatenates clouds directly; moving `/cloud_registered_body` cannot be substituted without transforming each scan to a common local frame.
- **Measured/read-only NX inspection:** the eco01 same-run `map_clean.ply` (4.2 MB) and `world.ply` (11 MB) exist. The former excludes the ceiling; the latter must be transformed from Voxel-SLAM world using the YAML `T_map_world` and cropped for outliers. In `socialtech:robot-nav`, Eigen 3.4, PCL 1.14 and oneTBB 2021.11 development packages exist; `numpy` exists, while Python `kiss_matcher`, `small_gicp` and `scipy` do not. These package observations preceded the isolated source builds below. No registration on real data has occurred.
- **Read upstream:** [KISS-Matcher](https://github.com/MIT-SPARK/KISS-Matcher) provides C++/Python registration and ROS2 examples; its published Linux Python wheels are x86_64, so a Jetson source build remains to verify. [small_gicp](https://github.com/koide3/small_gicp) provides a local registration/refinement library; it cannot by itself search the global map. A source or aarch64 wheel path is available, but its behavior in the pinned Jazzy image remains unverified. The pinned upstream versions and license analysis are in `01-investigacion-metodos.md`.
- **Measured, isolated source build on NX:** cloned KISS-Matcher at `8b58b118e00c7a5a22448741f8d956d638a44ae2` and small_gicp at `fa0cfc983417c044b6036f71dfa448038bb9c820` under `/home/jetson/work/global-reloc-3d-20261009/`. With `socialtech:robot-nav` (Jazzy, aarch64), small_gicp configured and built `libsmall_gicp.so` (confirmed ELF aarch64) using the command below. KISS-Matcher configured with system Eigen/TBB and downloaded pinned ROBIN and its build dependencies into the same scratch directory; `kiss_matcher_core` built successfully as `libkiss_matcher_core.a`. An initial default `cmake --build` also compiled unrelated ROBIN tests, so it was interrupted; the subsequent targeted core build completed. ROBIN emitted `control reaches end of non-void function` warnings in upstream source; this build does not resolve their runtime implications. No files were installed into the host, no robot image stage was changed, and no build container remains active.

```bash
docker run --rm --network none -v /home/jetson/work/global-reloc-3d-20261009:/src socialtech:robot-nav bash -lc 'cmake -S /src/small_gicp -B /src/small_gicp-build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTS=OFF -DBUILD_EXAMPLES=OFF -DBUILD_WITH_TBB=ON -DBUILD_WITH_OPENMP=OFF && cmake --build /src/small_gicp-build -j2'
docker run --rm --network host -v /home/jetson/work/global-reloc-3d-20261009:/src socialtech:robot-nav bash -lc 'cmake -S /src/kiss-matcher/cpp/kiss_matcher -B /src/kiss-build -DCMAKE_BUILD_TYPE=Release -DUSE_SYSTEM_EIGEN3=ON -DUSE_SYSTEM_TBB=ON -DUSE_SYSTEM_ROBIN=OFF'
docker run --rm --network none -v /home/jetson/work/global-reloc-3d-20261009:/src socialtech:robot-nav bash -lc 'cmake --build /src/kiss-build --target kiss_matcher_core -j2'
```
