**I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** convert both estimate and reference to the same declared body/base convention before scoring:

1. Full reference body pose: `T_map_imu_ref(t) = T_map_world * T_world_imu_ref(t)`.
2. For a physical chassis convention, use fixed `T_imu_base_link`, then planar projection to footprint. For the legacy proxy, project the reference IMU pose directly and name the proxy explicitly.
3. A LiDAR estimate is converted through `T_map_imu_est = T_map_lidar_est * T_lidar_imu`; never subtract the mount translation in world coordinates without rotating it.
4. A query-submap estimate expressed in odom may already be `T_map_odom`. Otherwise, `T_map_odom = T_map_body_est(t_q) * inverse(T_odom_body(t_q))`. Pose at a later available sensor time is `T_map_body_est(t) = T_map_odom * T_odom_body(t)`. Do not apply this conversion twice.
5. Score XY at that pose's represented time and yaw from the levelled orientation. Score 3D candidates' z/roll/pitch separately at the full IMU/body origin, before planar projection; footprint z=0 is not a 3D accuracy result.

## B3. Classification of each attempt

### Acceptance event and outcome

**I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** an attempt is one fixed method/config/seed applied once to one frozen eligible observation window and map. An acceptance is the first explicit commit-to-one-pose event of its declared acceptance policy, recorded before evaluator scoring. Merely publishing a candidate/TF, returning from a service, converging numerically, or shrinking covariance is not that event. Record both native acceptance and any external gate acceptance; never silently filter native wrong accepts out of the safety report.

**V, correctness requirement:** for a positive query, accepted pose is correct iff `sqrt(dx^2+dy^2) <=0.30 m` AND `abs(wrap(yaw_est-yaw_ref)) <=8 degrees` at the same represented timestamp/frame. Equality passes. Either limit exceeded is wrong acceptance. No 5 s reference-based hold is required for this initial-pose classification; sustained AMCL convergence is a separate B7 endpoint.

| Primary outcome | Definition / decided attribution |
|---|---|
| correct_accept | Valid acceptance before deadline and within both approved error limits |
| wrong_accept | Valid acceptance before deadline outside either limit; for a disjoint no-match negative, any acceptance is a false acceptance even though XY/yaw error in that unrelated map is undefined |
| correct_reject | No acceptance on a certified no-match negative; retain terminal reason explicit_reject, timeout or declared_ambiguity. A crashed process is not a correct rejection |
| false_reject_timeout | No acceptance on an eligible positive with a representable correct pose, ending in rejection or deadline; distinguish explicit rejection, timeout, frontend_not_ready and candidate crash/OOM |
| declared_ambiguity | Positive attempt returns multiple distinguishable hypotheses without committing to one. Report separately from explicit rejection/timeout; also count it in total positive non-acceptance |
| operational_failure | Crash/OOM on an intact no-match negative: no accepted pose, but no demonstrated correct rejection. Retain in valid negative denominators |
| invalid_unscorable | External input corruption/drops, leakage, time/frame mismatch, missing reference coverage or broken harness; kept in log, excluded from valid-trial rate denominators, rerun when possible |

**I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** classes are mutually exclusive. Keep flags `native_accepted`, `gate_accepted`, `ambiguity_reported`, `terminal_reason`, `truth_condition` alongside them. A no-match negative that declares ambiguity remains correct_reject with ambiguity flag. Crash/OOM on intact input is a method operational failure, not harness invalidity; it remains in valid-trial denominators and is never rewarded as a negative rejection. Use operational_failure as an additional explicit terminal outcome for negative crashes.

**I:** “correct pose exists” means map coverage and the reference frame make a correct answer representable, not that every scan is uniquely identifiable. Prelabel `positive_unique`, `positive_aliased`, `negative_no_match` or `truth_undetermined` without seeing candidate outcomes. Positive non-acceptance in aliased scenes is cautious behavior, so report that stratum separately. Truth-undetermined cases are diagnostic, not forced into success/failure rates. A top-K set containing the true pose without acceptance is retrieval recall, not correct_accept.

**I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** wrong acceptance is absorbing for an attempt: later correction cannot convert it into success. Within the bounded initial-localization attempt, any wrong committed replacement makes its primary outcome wrong_accept, even if the first acceptance was correct; retain first-acceptance precision/latency separately. Record all acceptance events and an any_wrong_accept flag. Later tracking errors after the initial attempt ends belong to B7's separate endpoint. No best-of-retries or best-of-seeds selection. Retries, searches over multiple tiles and verification calls share the same deadline/path/observation budget.

### Metric levels and project selection rule

### Covariance: two distinct questions

**Level 2 — secondary; not an evaluation gate.**

**I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** empirical between-attempt error covariance uses signed residual vectors, common map/body frame, yaw locally wrapped, sample mean removed, denominator N-1. **I — DECIDIDO (criterio delegado de Narcís, 2026-10-07; revisable por Narcís):** declared uncertainty calibration uses `d² = eᵀ Sigma⁻¹ e` (normalized estimation error squared; Mahalanobis distance is sqrt(d²)) in the covariance's declared coordinates, transported to the evaluation frame with the appropriate Jacobian/adjoint, including lever-arm conversion. Test XY and yaw separately when only those marginals are supplied; use full 3D translation/rotation tangent residuals only with a genuine full covariance and declared convention. Highly aliased/large-angle distributions violate local Gaussian assumptions; retain outliers and flag the limitation.

Solver Hessian inverse or wrapper fixed covariance is marked heuristic unless its noise/scaling convention is justified.
